# SQL Data Cleaning Project

This project focuses on cleaning and preparing raw data for analysis using SQL.

## Tools Used
- SQL (SQL Server)

## Project Overview

The dataset contained inconsistencies, incorrect formats, and duplicate values that required cleaning before analysis.

## Data Cleaning Steps

- Removed duplicate records
- Standardized categorical values (e.g., payment methods)
- Converted data types (e.g., float to decimal)
- Handled missing or inconsistent values
- Reformatted columns for better usability

## Key Transformations

- Ensured numerical accuracy by adjusting data types
- Improved consistency in categorical fields
- Prepared dataset for further analysis and reporting

## Outcome

The cleaned dataset is structured, consistent, and ready for analysis or dashboard creation.
